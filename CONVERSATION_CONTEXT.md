# SEO Page Generator - Complete Conversation Context

## Project Overview

An internal tool for SEO team to automatically generate and publish SEO-optimized location/service pages to client WordPress sites using AI.

## Key Decisions Made

### Tech Stack

- **Frontend/Backend:** Next.js 14 + React + TypeScript
- **Styling:** Tailwind CSS
- **Database:** Neon PostgreSQL (FREE tier)
- **ORM:** Prisma
- **Auth:** Clerk (FREE tier - 10,000 users)
- **AI Content Generation:** Claude Code (uses Claude Pro subscription - NO API costs)
- **WordPress:** REST API + Elementor
- **Hosting:** Vercel (FREE tier)

**Total Monthly Cost:** $20 (just existing Claude Pro subscription)

### Why Claude Code (NOT OpenAI API)

- User has Claude Pro subscription ($20/month)
- Claude Code CLI tool uses Pro subscription
- Zero additional API costs
- No API key management needed

### 5. Content Generation Rules (SOP)

**Page Types:**

- Primary Service Pages
- Nested Broad Stroke (County-level)
- Broad Stroke (Town-level)
- Location Service Pages (Town + Service)

**Content Structure:**

- Meta Title (include company + primary keyword)
- Meta Description (≤155 chars, include "Call now!")
- H1 (primary keyword)
- Hero Description (50-60 words)
- Benefits Section (H2 + subheading + 3 bullets ≥30 words each)
- Why Section (H2 + subheading + 3 bullets ≥30 words each)
- FAQ Section (3 Q&As, SEO-relevant, company name in 2nd half of answer)
- Map Section (H2 + 50-60 word description)

**Primary Keyword Generation:**

- Format: [Unique Adjective] + [Service] + "in" + [Location]
- Example: "Professional Commercial Glass Installer in Sumner, WA"
- Adjectives must be unique per batch (generated by Claude)

### 6. Validation Rules

```javascript
{
  meta_description: {
    max_length: 155,
    must_include: ["call_now"],
    action: "regenerate"
  },
  bullet_points: {
    min_words: 35,
    must_start_with_bold: true,  // <b>Topic:</b>
    action: "regenerate"
  },
  faqs: {
    must_be_seo_relevant: true,
    must_use_primary_keyword: true,
    company_name_in_second_half: true,
    not_company_promotional: true,
    action: "regenerate"
  },
  links: {
    internal_count: 1,
    external_count: 1,
    style: "text-decoration: underline; display: inline",
    action: "fix"
  }
}
```

### 7. Link Rotation Rules

**Internal Links:**

- Rotation for 3 pages: [hero, faq-a1, map]
- Rotation for 5 pages: [hero, faq-a1, faq-a2, faq-a3, map]
- Rotation for 10 pages: repeat 5-page pattern twice
- If map omitted on position 3: use faq-a3
- If map omitted on position 5: use hero
- Anchor: company name
- Link to: company homepage

**External Links:**

- Rotation: [benefits-1, benefits-2, benefits-3, why-1, why-2, why-3]
- Repeats for batches >6 pages
- If section omitted: skip to next position
- Anchor: full location name (e.g., "Sumner, WA")
- Link to: city official website or Wikipedia

### 8. CSV Structures

**Client Metadata CSV (one-time):**

```csv
Client Name, Client Website, WordPress URL, WP Username, WP App Password, SEO Plugin, Template Page ID
```

**Pages CSV (monthly):**

```csv
Client Name, Page Type, Page Name, External Link Section, Omit Sections
```

Example:

```csv
Kowalski Painting, Location Service, Roof Repair in Gilbert AZ, ,
Carter's Painting, Broad Stroke, Services in Newberry FL, , FAQ
```

### 9. Content Generation Flow

```
1. User uploads Pages CSV
2. App parses rows
3. For each row:
   a. Extract service + location from page name
   b. Use Claude Code to generate:
      - First: unique adjectives for all pages in batch
      - Then: full content with primary keyword
   c. Apply section omission rules
   d. Validate content against rules
   e. If validation fails: regenerate (max 3 attempts)
   f. Insert internal/external links per rotation
   g. Fetch Elementor template from WordPress
   h. Update template JSON with content
   i. Publish via WordPress REST API
   j. Save to database (time taken, status)
4. Show completion report
```
